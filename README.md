# 전자출결시스템 관리자 테스트 페이지

관리자 화면 세부기획서를 기준으로 만든 **정적 SPA 프로토타입**입니다. GitHub Pages에서 별도 빌드 없이 실행할 수 있습니다.

## 최초 로그인

- 개발자: `admin` / `1234`
- 담당 PM: `pm` / `1234`
- 전형관리자: `exam` / `1234`
- 고사장·건물관리자: `building` / `1234`
- 현장관리자: `field` / `1234`

## 포함 기능

- 공통 로그인과 계정 권한별 첫 화면/메뉴 분기
- 개발자의 학교·전형·담당 PM 관리
- 담당 PM의 대학 관리자 계정 생성과 범위 설정
- 학교별 명칭 수정: 고사장→고사실, 중간관리자→복도관리자 등
- 시험 기본정보와 최대 3교시 시간 설정
- 학교별 기능 ON/OFF
  - 마감, 예비고사실, 정·부 감독관, 답안지
  - 감독관 고사실 배정 필수/선택
  - 고사실별 잔여좌석 표시
  - 사고유형, 사진 비교
- 파일 선택 즉시 업로드·컬럼 매칭·오류 검증
- PDF 페이지당 인원, 정/부/예비감독관 서명 대상 선택, 정렬과 미리보기
- 그래프형 대시보드(기본), 엑셀형 목록, 특이사항, 사진 비교
- 마감 전 점검, 마감·해제, 결과파일 다운로드

## 실행

### 가장 간단한 방법

`index.html`을 브라우저에서 엽니다.

### 로컬 웹서버

```bash
python -m http.server 8080
```

브라우저에서 `http://localhost:8080`으로 접속합니다.

## GitHub Pages 배포

1. 이 폴더의 모든 파일을 저장소 루트에 복사합니다.
2. GitHub 저장소의 **Settings → Pages**로 이동합니다.
3. Branch를 `main`, Folder를 `/ (root)`로 선택하고 저장합니다.

## 엑셀 자동검증

브라우저에서 XLSX 파일을 읽기 위해 SheetJS CDN을 사용합니다. 인터넷 연결이 없으면 데모 검증 데이터로 동작합니다. 운영 개발 시에는 서버 업로드 후 백엔드 검증 API로 교체하는 것을 권장합니다.

## 데이터 저장

프로토타입 설정과 로그인 상태는 브라우저 `localStorage`에만 저장됩니다. 상단의 **데모 초기화** 버튼으로 초기화할 수 있습니다.
